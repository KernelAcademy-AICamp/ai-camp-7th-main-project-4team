PRD 1_제품정의 · 플로우 3_사용자플로우
2026-07-28

사용자가 홈에 들어와 → 진단하고 → 결과를 받고 → 그 결과로 옷을 판정하고 → 전문가로 넘어가기까지의 한 줄기 흐름. ★ = MVP에서 실제로 만드는 화면.

가입은 나중에
비회원으로 진단~결과~피드백까지 다 간다. 가입은 결과 저장·매칭 이용 두 순간만.
진단은 동의 게이트 없이
시작을 막지 않는다. 엔진 개선 목적 활용만 결과 화면에서 opt-in.
막다른 길 금지
실패·빈 화면에도 돌아갈 길을 둔다(추정 실패→옷 추가, 신뢰도 낮음→재진단).

기본 정보 입력★
성별 · 나이 · 키 · 몸무게. 성별을 고르면 평균값을 미리 채워 입력 부담을 줄인다.

착용경험 보정★정확도의 핵심 입력
옷 종류(상의/하의)·선호핏 → 입어본 옷 1~3벌[브랜드+핏+사이즈] → 부위별 느낌(큼·여유·딱맞음·끼임). 이 답으로 체형을 거꾸로 계산한다.
0벌이면건너뛰기 가능 — 대신 신뢰도 '낮음'으로 결과가 나간다

진단 로딩★
서버 엔진이 체형 역산 → 브랜드 사이즈 매칭 → AI 설명 문장 순으로 처리. 숫자는 규칙, 문장만 AI.
갈림길확신 못 함(신뢰도 낮음) → "옷을 더 추가해 주세요" → 2-2로 되돌림
2-4
결과 카드 — 제품의 얼굴★ Aha
① 체형 프로필(8유형 캐릭터) ② 핏 인사이트 ③ 브랜드별 추천 사이즈 + 옷장 · 신뢰도 3단계(0벌 낮음 / 1벌 보통 / 2~3벌 정확).
"안 입어본 브랜드인데 이 사이즈면 맞겠다"는 확신이 처음 서는 지점.
가입 ①결과 저장을 누를 때만 가입 모달. 비회원은 임시 링크로 보관(만료 있음) · 저장 안 해도 흐름은 계속
되돌기재진단 / 옷장에서 다음 종류 이어서 진단(기본정보·체형 재사용) → 2-2
2-5
피드백 — 측정 지점★
"실제 내 사이즈와 맞나요?" 동의/비동의 · "안 사본 브랜드도 사보겠어요?" 의향 · 엔진 개선 opt-in(만 14세 확인 접목).
★ KILL METRIC아는 브랜드 검증 기준 사이즈 정확도 ≥ 65% · 보조 — 타브랜드 구매 의향 ≥ 50%
2-8
구매 판정(Fit)으로 분기★
결과 하단 판정 바 — "지금 사려는 그 옷, 나한테 맞을까". 진단이 내 몸이라면 판정은 그 옷 한 벌. → 2쪽 상세 흐름
2-6
전문가 전환 — 무료→유료의 다리★
"스타일까지 전문가에게 받기". 사이즈는 풀렸으니 남은 축(스타일 어울림 40%)으로 넘긴다.

가입 ②구경·유형 선택까지 비회원. 알림신청/요청을 누르는 순간 가입 관문

구매 판정(Fit)
— "이 옷, 나한테 맞을까" · 결과·마이의 판정 바에서 진입

진단 결과가 판정의 기준이 되므로 진단 → 판정 순서가 고정. 진단 없이 들어오면 진단으로 유도한다. 이 흐름은 같은 엔진을 재사용하면서, 올라온 사이즈표를 실측 자산으로 회수하는 수집 경로이기도 하다.

①
판정 기준 = 내 체형★
현재 세션의 진단 결과·8유형이 자동으로 세팅된다(고를 필요 없음).
진단 없음"판정 기준이 없어요 — 먼저 진단하기" → 2-1 기본정보로
②
옷 종류 선택★
상의 / 하의 — 볼 부위가 달라진다(상의=어깨·가슴 / 하의=허리·엉덩이·허벅지).
③
사이즈표 올리기★
캡처 업로드(붙여넣기·드래그·선택 → AI 인식) 또는 직접 입력. 인식 결과는 표에서 바로 수정 가능.
수집 동의선택 — "판정을 더 정확하게 하려고 사이즈표를 활용할게요" 체크 시 브랜드·상품명 입력. 판정 자체는 사이즈만 있으면 실행
▶
판정 로딩★
카드 뒷면이 먼저 서고, 결과가 오면 그대로 뒤집힌다(크기 점프 없음).
핵심 부위 없음"판정할 수 없어요" — 근거 없으면 긍정하지 않는다 → 사이즈표 다시 올리기
✓
판정 결과★
① 추천 사이즈 + 핏 게이지 ② 사이즈별 판정 표(끼임 · 딱맞음 · 여유) ③ 부위별 근거(수치 · 체형 그림). 세로축(총장·기장)은 정보 라인으로만 표시.
📥
사이즈표 수집 — 자산화 루프★
동의했다면 garment_submission 저장(멱등) → 운영자 검수 → 정본 garment로 승격. 다음 사용자의 판정·진단이 그만큼 정확해진다.
구조적 이득쓸수록 브랜드 커버리지가 늘어난다 — 실측 확보(최대 난관)를 사용자 힘으로 푸는 경로
