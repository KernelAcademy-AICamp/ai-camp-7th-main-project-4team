판정 화면 · 전체 배치 4안
"사이즈표 입력 → 판정 → 결과"를 한 화면에 어떻게 앉히느냐의 구조만 비교해요. 색·글씨·디테일은 뺀 뼈대(와이어프레임)예요. 핵심 질문은 입력과 결과를 같은 자리서 바꿀지 / 나란히 둘지 / 이어서 흐르게 할지.
1좌우 2단지금 방식
왼쪽에 입력 레일 고정, 오른쪽 넓은 캔버스. 판정 전엔 안내, 판정 누르면 같은 자리가 결과로 바뀜.
